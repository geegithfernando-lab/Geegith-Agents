Start here: 5 steps
  1. Open Settings, pick a preset (SPQR or Wedding Bar) or edit the niche, and set your monthly earnings goal.
  2. Open Agents and tap Run full cycle. Allow Claude access when asked.
  3. Open Queue. For each draft, write your own contribution, tick the AI label, then move it to approved.
  4. Make the videos in your tools, upload or schedule them in Meta Business Suite, then mark the post posted.
  5. Log views and earnings after posting. Open Dashboard to see your progress.
What each tab does
  • Command: every panel on one screen, like a control-room wall. Tap another tab to focus on one panel.
  • Dashboard: earnings ring against your goal, 6-month chart, key numbers, and the next best action.
  • Agents: the six-agent cycle that produces research, ideas, scripts, visual prompts, a compliance check, and post drafts.
  • Ops: four on-demand agents for security, settings, accounts, and earnings.
  • Queue: drafts, approval, week view, hook variants, repurposing, and results.
  • Connections: setup steps and security checks for your tools.
  • Telemetry: live visuals of agent activity.
  • Settings: appearance, agent behavior, approval rules, earnings goal, and data.
Tutorial: run your first cycle
  1. Go to Settings and check the niche text, tone, language, and posts per cycle.
  2. Go to Agents and tap Run full cycle.
  3. Watch the pipeline strip at the top. A glowing circle means that agent is working. Tap any agent card to read its full output.
  4. When all six are done, the Publisher adds drafts to the Queue.
  5. Use Stop if you want to cancel. The log at the bottom shows what happened.
The six agents: Researcher, Strategist, Scriptwriter, Visual Director, Compliance, Publisher. Each one reads the earlier agents’ output. Research uses general knowledge, not live web data.
Tutorial: approve and post a draft
  1. In Queue, read the caption and hashtags.
  2. Write your own contribution: your angle, voice, edit, or research. This is what makes the post original.
  3. Tick “AI label added” once you have added the label where Meta requires it.
  4. Change the status: draft, review, approved, scheduled, posted.
  5. Approval is blocked if your contribution or label is missing, the post is too similar to another, or it contains a blocked word.
  6. After posting, enter views, retention percent, and shares. The agents use these numbers next cycle.
Extras: “3 hook variants” writes alternative openings. “Repurpose” makes different versions for other platforms. “Copy” copies the caption and hashtags. Export CSV saves the whole queue.
Tutorial: track your earnings
  1. Set your monthly goal and currency in Settings → Earnings.
  2. Copy the amount from Meta’s own earnings page.
  3. On Dashboard, use Log earnings: pick the date, type the page and amount, tap Add.
  4. The ring fills toward your goal. The projection assumes the same daily pace for the rest of the month.
  5. Tap remove next to a recent entry to delete it.
The app cannot read Meta earnings automatically. You enter them yourself.
Tutorial: use the Ops agents
  • Security Agent: tap Run for a risk score and fix list based on your Connections.
  • Settings Agent: suggests changes. Tap Apply to accept. It can only make your safety rules stricter.
  • Accounts Agent: paste comments into the box on the Ops tab first to get draft replies. Always read and post replies yourself.
  • Earnings Agent: compares your earnings with your goal and ranks actions.
Tutorial: set up Connections safely
  1. Open Connections and expand a tool.
  2. Follow its three setup steps, using the official site link.
  3. Set the status to In progress, then Connected when done.
  4. Tick each security check only after doing it inside that tool.
  5. Tap Mark reviewed. After 90 days it shows Review due.
Never type passwords, API keys, or tokens anywhere in this app. Notes that look like secrets are not saved, and cycles are blocked until you remove them.
Tutorial: monthly security review
  1. Open Ops and run the Security Agent.
  2. Open Connections and re-check two-factor, access levels, and where keys are stored for each tool.
  3. Tap Mark reviewed on each one.
  4. Check that Security health is above 75 percent.
If an account may be compromised, use the checklist at the bottom of Connections right away.
Tutorial: automatic scheduling (advanced)
  1. Export the CSV from Queue and put approved rows in a Google Sheet.
  2. Run Postiz (self-hosted or cloud) and connect your Facebook Page on Postiz’s own login screen.
  3. In Postiz settings, copy the API key into n8n’s credential store, never into this app.
  4. Build an n8n workflow that reads approved rows, uploads the video, and schedules the post.
  5. Confirm in advance that Postiz can publish Reels to your Page.
This runs outside the app. The app cannot post by itself.
Tutorial: run it on your iPhone without Claude
  1. Put the file on a free web host: GitHub Pages, Netlify or Cloudflare Pages. Name the file index.html.
  2. Open the page address in Safari on your iPhone.
  3. Tap Share, then Add to Home Screen. It opens like an app with the Geegith icon.
  4. Open Settings → AI engine, paste your Anthropic API key, and tap Test connection.
  5. Create the key in your Anthropic Console account and set a low spending limit on it.
Your settings, queue, and earnings stay in that browser on that phone. Export settings and the queue CSV now and then as a backup.
Settings guide
  • General: preset, niche, tone, language, posts per cycle, performance notes, auto-run.
  • Appearance: theme, accent color, text size.
  • Agents: turn agents off, set creativity and length, add house rules and blocked words.
  • Approval rules: require your contribution and the AI label, and set the duplicate limit. Lower means stricter.
  • Earnings: monthly goal and currency symbol.
  • Data: export settings or reset to defaults.
  • Privacy: choose whether notes go to agents, or erase all local data.
Troubleshooting
  • Run button is grey: there is no AI engine yet. Add your API key in Settings → AI engine, or open the app inside the Claude app.
  • “Blocked” message: a field looks like a password or key. Remove it from Settings or Connections.
  • A cycle stops early: check the log for the failing agent. Wait a minute and run again if it says rate limited.
  • Queue stays empty: the Publisher output was not valid. Run the cycle again.
  • Can’t approve a post: check your contribution, the AI label, the duplicate warning, and blocked words.
  • Copy does nothing: your device blocked it. Long-press the text instead.
  • Data missing: data lives in this browser only. A different device or cleared browser data starts fresh.
  • Battery use: turn off ring animation in Settings.
FAQ and limits
  • Does it post for me? No. You upload or schedule in Meta Business Suite, or use the Postiz and n8n route.
  • Does it run in the background? No. Only while the page is open.
  • Is research live? No. It comes from Claude’s general knowledge.
  • Where is my data? In your browser only. Prompts go to Claude when you run an agent.
  • Why the approval gates? Meta favors original, human-directed content over mass-produced posts. Check Meta’s current rules yourself.
